# **09 - NEIGHBORHOOD ANALYSIS**

## **Overview and objectives**

The aim of this analysis step is to characterize cell neighborhoods in each sample of the merged TMA dataset. In spatial transcriptomics, neighborhood analysis consists of clustering cells by jointly leveraging their molecular profiles and spatial context. In this framework, neighborhoods are defined as groups of cells sharing a similar local microenvironment.

Specifically, this is achieved using BANKSY, which constructs a neighbor-augmented expression matrix by integrating each cell’s own transcriptome with the transcriptomic information of its spatial neighbors. Standard clustering methods are then applied to this augmented representation, similarly to single-cell RNA-seq analysis. However, in this context, the resulting clusters do not represent cell types, but instead correspond to spatially defined cellular neighborhoods.

Once these neighborhoods are defined, their cellular composition can be characterized in terms of cell types, and correspondence between similar neighborhood structures across different samples can be assessed.

## **02_Banksy_Analysis.R**

### 1. BANKSY analysis

The aim of this analysis is to perform neighborhood analysis using BANKSY with default parameters, as described previously. This analysis is conducted independently for each sample.

By exploring multiple clustering resolutions, this approach enables the identification of cellular neighborhoods at different levels of granularity. Higher resolutions allow the detection of more specific and well-resolved tissue structures (e.g., blood vessels) that may be obscured within broader regions at lower resolutions, whereas lower resolutions capture more general tissue organization.

These neighborhoods can be interpreted as spatially coherent tissue regions within each sample.

In this step, the following sections are provided to visualize the results of the BANKSY analysis.

  - For each sample and each clustering resolution tested:
    * Clusters: UMAP visualization of cell clusters obtained from the neighbor-augmented expression matrix generated by BANKSY. These clusters correspond to spatial neighborhoods within the sample.
    * Tissue: Spatial visualization of the identified clusters (neighborhoods) mapped onto the tissue.
    * Cluster X: Visualization of individual cluster (neighborhood) on the tissue.

### 2. Merge BANKSY analysed samples

This step aims to merge the individual sample Seurat objects containing the results of the BANKSY analysis.

Note that BANKSY includes a data scaling step as part of its workflow. Because the analysis was performed separately for each sample, this scaling was applied independently at the sample level. As a result, the merged neighbor-augmented expression matrix may not be directly comparable across samples and should therefore be used with caution in downstream analyses.

## **03a_Characterize_Sample_Wasserstein.R**

Now that BANKSY neighborhoods have been defined for each sample, they can be further characterized in greater detail.

This step aims to compare BANKSY neighborhoods within each sample using the sliced Wasserstein distance. The Wasserstein distance can be interpreted as the amount of “mass” that must be transported to transform one neighborhood’s spatial distribution into another. In this context, a smaller distance indicates that two neighborhoods are more similar in their spatial organization within the tissue.

Here, the sliced Wasserstein distance is used, which is an approximation of the full Wasserstein distance that enables faster computation while preserving meaningful comparisons between distributions.

## **03b_Characterize_Sample_JS.R**

Similarly, BANKSY neighborhoods within a sample can also be compared using the Jensen–Shannon divergence, a metric used to quantify the similarity between two probability distributions. In this context, the cell-type composition of each neighborhood is considered as its probability distribution.

To construct these probability distributions, cells belonging to a given BANKSY neighborhood are first subsetted. For each cell, its k-nearest neighbors are identified, and the cell-type composition within this local neighborhood is retrieved. The probability distribution for a given BANKSY neighborhood is then obtained by averaging these local cell-type compositions across all cells in that BANKSY neighborhood.

A smaller Jensen–Shannon divergence between two BANKSY neighborhoods indicates that their average cell-neighbors cell-type compositions are more similar.

Using both the sliced Wasserstein distance and the Jensen–Shannon divergence allows comparison of neighborhoods within a sample by quantifying their similarity in terms of spatial organization and cell-type composition of local microenvironments.

One potential application of these similarity measures is to assess whether the clustering resolution used to define neighborhoods is too high. In such cases, neighborhoods may be over-segmented, and highly similar clusters could correspond to the same underlying tissue region. These neighborhoods can then be considered for merging to obtain a more biologically meaningful representation of tissue structure.

## **03c_Compare_Intra_Sample_Neighborhoods.R**

This step aims to visualize the intra-sample comparison of neighborhoods using the sliced Wasserstein distance and the Jensen–Shannon divergence. The following outputs are provided to illustrate this comparison:

For each sample and clustering resolution combination, two heatmaps are displayed:

  - A heatmap showing pairwise comparisons between neighborhoods within the sample using the Jensen–Shannon divergence.
  - A heatmap showing pairwise comparisons between neighborhoods within the sample using the sliced Wasserstein distance.

For both heatmaps, the relative cell-type proportions of each neighborhood are displayed alongside the matrix. The neighborhood indices are indicated on both the rows and columns of the heatmaps. 

The Jensen–Shannon divergence and sliced Wasserstein distance values are highlighted in blue in the heatmap when both metrics meet the thresholds defined in analysisParams.R. When both criteria are satisfied, this indicates BANKSY neighborhoods that may be candidates for merging, as they likely represent the same underlying tissue region.

## **03d_Random_Neighborhoods_Comparison.R**

This step aims to compare the average cell-neighbors cell-type compositions of BANKSY neighborhoods to a random distribution of cell-neighbors cell-type compositions.

This random distribution is obtained by performing N random samplings of X cells, and computing the average cell-neighbors cell-type composition for each sampling. For each cell in a given sampling, its K nearest neighbors are identified, and their average cell-neighbors cell-type composition is computed as described previously.

The following sections are then provided to compare BANKSY neighborhood compositions with those of randomly sampled neighborhoods:

For each sample:

  - Cell type distribution in random neighborhoods: Boxplots showing the distribution of cell-type proportions obtained from randomly sampled cells within the current sample.

For each clustering resolution used in the BANKSY analysis:

  - A red dot is overlaid on each boxplot, representing the average cell-type proportion in the cell-neighborhoods of the corresponding BANKSY clusters. This allows direct comparison between observed neighborhood compositions and those expected under random sampling.

## **04_Compare_Inter_Sample_Neighborhoods.R**

Similarly to the intra-sample comparison of neighborhoods, inter-sample comparisons of average cell-neighbors cell-type composition in BANKSY neighborhoods can be performed using the Jensen–Shannon divergence.

This analysis enables the identification of similarities between neighborhoods across different samples and helps to highlight corresponding or shared tissue regions.

For each clustering resolution, a heatmap is displayed showing pairwise comparisons between neighborhoods across samples using the Jensen–Shannon divergence.

On the right side, the cell-type proportions corresponding to each neighborhood are shown. On the left and top margins, a color bar indicates the sample of origin for each neighborhood, along with the corresponding BANKSY neighborhood index within the sample.

## **05_Merge_Samples_Neighborhoods.R**

This step aims to harmonize BANKSY neighborhoods across samples by assigning a common neighborhood index to neighborhoods considered to be similar.

To achieve this, a simple hierarchical approach is used to identify similar BANKSY neighborhoods. Specifically, the dendrogram obtained from the heatmap based on Jensen–Shannon divergence is used to define groups of similar neighborhoods. A predefined number of hierarchical clusters is extracted from this dendrogram, and BANKSY neighborhoods belonging to the same hierarchical cluster are considered equivalent. Their identifiers are then harmonized by assigning a shared index across samples.

### 1. Merge samples neighborhoods - Heatmaps

In this step, the following sections are provided to visualize the neighborhood merging process:

For each resolution and each predefined number of hierarchical clusters:

  - A heatmap similar to the one described in the previous section is displayed. In addition, an additional color bar is shown on the left side of the heatmap, indicating the hierarchical cluster assignment of each BANKSY neighborhood.

### 2. Merge samples neighborhoods - Tissue view

In this step, the following sections are provided to visualize the neighborhood merging process:
