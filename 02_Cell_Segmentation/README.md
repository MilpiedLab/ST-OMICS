# **02 - CELL SEGMENTATION**

## **Overview and objectives**

In Xenium output files, a segmentation generated by the built-in Xenium segmentation tool is already provided for the dataset. However, this segmentation is image-based and relies on nuclear and membrane staining. It does not account for important limitations, such as transcript diffusion outside of cells during the tissue processing or the three-dimensional nature of the tissue, where overlapping cells can lead to inaccurate segmentation. Failing to account for these limitations leads to less accurate cell segmentation and can compromise all subsequent steps in the workflow, including cell type annotation, neighborhood analysis, and cell–cell communication.

The aim of this analysis step is therefore to refine the Xenium-provided segmentation using Proseg (probabilistic segmentation). This tool is designed to address the limitations described above and improve upon the initial cell segmentation by producing a more accurate result. For more information, see: https://github.com/dcjones/proseg

This analysis step, based on Proseg 3, is more broadly implemented within PASTIS, a Snakemake pipeline. PASTIS streamlines the workflow by taking Xenium output as input, running Proseg to refine the segmentation, and then converting the results back into a standard Xenium format. These outputs can subsequently be loaded into a Seurat object using the Read10X functions.

The PASTIS pipeline also supports grid search for hyperparameter optimization. Specifically, for three Proseg parameters (“diffusion_probability”, “voxel_layers”, and “nuc_assignment”), a range of values can be defined (see expert_config.yaml). The Snakemake pipeline then automatically processes the selected sample(s) using all possible combinations of these parameters. Running the analysis with multiple parameter sets makes it possible to identify the configuration that yields the highest-quality cell segmentation (see 03_Proseg_Hyperparameter_Search analysis step).
